## 1. 方案摘要

首版提供面向所有人的**私人住宅租金趋势**浏览工具，不按续租、搬家或赴港人群拆分产品。用户通过官方数据实际支持的住宅类别及地域，查看最新变化、历史曲线和可比系列，降低理解统计表及查找数据的成本。**租金指数为主，平均租金为独立辅助视图**；默认近一年，可切换近三年、近五年。页面区分最新统计月环比／同比与所选时间区间累计变化，并提供可展开的月度数据表。

只给有数据依据的事实型解释，不给涨跌原因、未来预测、单套合理租金、屋苑估价或租住推荐。免登录浏览，不新增收藏、提醒、分享、导出、个人租金输入或预算功能。平均租金未完成核验时不阻塞指数首版，也不展示无内容的辅助标签页；指数自身仍必须完成数据核验才能上线。

本文将信息分为三类：**已确认事实**来自已读代码和官方目录；**已定决策**来自本次讨论；**拟议设计／待确认**包括新 API、存储、调度、图表实现、入口归组及尚未读取的源字段。任何待确认项都不能在实施时静默视为定案。

### 1.1 关键结论表

| 维度 | 已定结论或现状 | 影响与边界 |
| --- | --- | --- |
| 产品定位 | 通用私人住宅租金趋势；看懂为主、查找比较为辅 | 不限制使用者，但不覆盖办公室、商铺、工厂等非住宅 |
| 地域 | 做到核实后的实际可用粒度 | 未确认十八区、片区或屋苑时间序列；全港指数不能包装成地区指数 |
| 指标 | 指数为主，平均租金独立辅助 | 指数不是港币；平均租金不是单位报价；不共用纵轴 |
| 时间 | 默认近一年，可切三年、五年 | 按最新可用统计月份回看，不强行补到今天；首版不加全部历史 |
| 比较 | 同屏最多三条可比系列 | 不混合不同指标、单位或统计口径，不做排名／热力地图 |
| 内容与操作 | 事实型摘要、交互图表、折叠月度表、来源说明 | 不分析原因、不预测、不增加个人化操作 |
| 异常 | 保留最近有效数据；缺值断线，涨幅不可算时显示暂无 | 不填零、不插值、不把同步失败当成官方未发布 |
| 上线门槛 | 指数可独立上线；平均租金核实后再开放 | 目录存在不是字段、质量、许可与部署验证通过 |
| 工程现状 | Flutter + FastAPI + PostgreSQL；已有通勤独立 worker | 租金模块尚不存在；拟复用基础能力，不新增队列或缓存服务 |

## 2. 背景、目标与范围

### 2.1 用户问题

原调研将租金走势与生活成本列为备选方向。本轮决定收窄为租金趋势，而非个人预算工具。不同使用者共享同一套事实浏览能力：续租者理解市场背景，换房者了解租金变化，赴港者认识市场，关注者查看长期变化。产品不替他们作决定，也不根据人群切换统计口径。

需要回答的共同问题：

1. 最新可用统计月是什么，租金较上月和去年同月发生了什么变化？
2. 关心的、实际受数据覆盖的类别或地域，在近一年／三年／五年如何变化？
3. 同一指标、可比口径的不同系列，其变化路径或租金水平有何差异？
4. 这些数字来自哪里，适用于什么范围，有哪些不能由它推导的结论？

“官方月更”不等于用户每月回访；实际使用价值尚未验证。首版价值验证看用户能否找对系列、读对变化与边界，不预设回访、付费或传播效果。

### 2.2 首版范围

- 私人住宅；指数主视图与核验后可用的平均租金辅助视图。
- 最新月摘要，近一年／三年／五年历史曲线，区间变化。
- 已核实的系列选择；最多三条同指标可比系列。
- 月度数据表、统计定义、来源、覆盖期和数据状态。
- 免登录；沿用 App 现有语言能力和 UI 结构。

### 2.3 明确非目标

- 楼价、收益率、空置率、成交量和生活成本综合仪表板。
- 非住宅租金，逐套挂牌／成交数据库，新增商业数据或挂牌抓取。
- 屋苑、小区、楼栋、单位估价；无数据支持的地址搜索、地区下钻或地图。
- 标准个人生活费、续租涨幅裁决、留住与搬家账本、个人租金对照。
- 原因分析、AI 解读、预测、合理租金区间、投资或租住建议。
- 登录、用户档案、收藏、提醒、分享、下载、导出、Widget、排行榜。
- 提前建设统一开放数据平台、通用爬虫集群、队列或新的缓存服务。

## 3. 页面与交互设计

### 3.1 信息结构

页面名称建议为“租金趋势”，页面顶部显眼标注“私人住宅／统计参考”。名称与首页归组仍为文案建议，不能暗示覆盖所有租赁市场。

| 顺序 | 页面区域 | 内容与行为 |
| --- | --- | --- |
| 1 | 标题与范围 | 私人住宅、当前系列的地域／类别、数据来源简称 |
| 2 | 指标切换 | 默认租金指数；平均租金只有核验并具备有效数据后才出现 |
| 3 | 系列筛选 | 当前指标实际支持的选项；禁止构造没有对应源系列的组合 |
| 4 | 最新摘要 | 统计月份、原值及单位／基期、环比、同比、事实型摘要 |
| 5 | 趋势卡片 | 一年／三年／五年切换、月度曲线、点选月份和值、区间起止与变化 |
| 6 | 比较操作 | 主系列之外最多两条可比系列；清楚的图例及移除操作 |
| 7 | 月度数据表 | 默认折叠；与曲线相同的指标、筛选和快照；含缺值原因和源标记 |
| 8 | 数据与口径 | 统计范围、单位／基期、最新覆盖月、同步状态、修订／暂定说明和官方链接 |

页面示意仅描述结构，不包含真实统计数值：

```text
租金趋势
私人住宅 · 当前地域／类别

[租金指数] [平均租金：可用时才展示]
[已核实类别] [已核实地域：该指标支持时才展示]

截至 YYYY-MM
原值／单位或基期    环比    同比
基于以上数据的事实型一句话

[近一年] [近三年] [近五年]
月度折线图 · 可查看各月数值
起止 YYYY-MM → YYYY-MM · 区间变化
[添加比较：最多三条]  图例与系列全名

[展开月度数据]
[统计口径与来源]  同步状态
```

### 3.2 默认值与筛选（拟议）

- 首次进入默认指数、近一年、单系列；若源提供并已核实全港整体系列，以其为主系列。**不能自行平均类别指数造出“整体”**；没有官方整体系列时，默认类别需评审确认并直接标明。
- 仅按当前指标的有效系列目录生成筛选。若指数只有全港，地域显示“全港”，不放不可用的地区下拉框。
- 面积类别若经核实，以面积定义为主、官方类别代码为辅；平方米／平方呎换算只作标签辅助，必须明确面积基准，不能把类别改成卧室数或“小户型”等未经验证含义。
- 指标切换时清除不兼容的比较项。能准确映射当前地域和类别才保留选择，否则回到该指标的已核实默认系列并提示；不按同名文本猜测对应。
- 不构造地域 × 类别的笛卡尔积。缺少对应源系列时，不把选项展示成“零租金”。
- 拟仅在页面会话中保留当前选择；关闭后重新进入使用默认值，不新增持久化偏好。是否改变此行为属于后续评审项。

### 3.3 单系列、比较与坐标

- 初始图表展示官方原值。指数标示官方基期，平均租金标示经核实单位；不能显示成未核实的“每套每月租金”。
- 添加比较只列出同指标、可比口径系列；最多三条包含主系列。保留用户选择顺序，不按涨幅或高低重新排序。
- 原值比较要求单位、指数基期、频率、方法及可比较范围一致。不同类别指数的绝对数值高低不代表金额高低。
- 需要查看相对变化时，拟提供显式的“相对变化（起点＝100）”模式，保留原值模式；是否首版增加该开关仍为实现细节待确认，不默认替换官方值。
- 多系列时最新摘要拟保持主系列，不做三组大卡片；其他系列在图例、选中月份面板、区间摘要和表格展示。该布局待 UI 评审。
- 不使用平滑曲线、双纵轴或预测段。图表按真实日历月份定位；缺失月份断线，不让缺失记录被连成连续月度路径。
- 坐标轴自动范围必须显式标出刻度，不隐去单位或通过动画放大涨跌；相对模式的 100 为比较基准，不是官方基期。

### 3.4 视觉与无障碍

复用 `docs/UI风格规范.md` 的结构 Token：`AppTheme` 圆角、卡片、间距、字体与品牌；页面级加载沿用 `HkSailLoader`。工具强调色由所属分组经 `ToolAccents.forGroup()` 取得，不另建一套视觉语言。

涨跌使用“上涨／下降／持平”、正负号及数值，不用红绿暗示利好利空。多序列优先用线型、点形和文字图例区分；如需多色，仅从 `ToolAccents` 取分类色，不改变模块主强调色、不用状态色编码系列。颜色不是识别唯一依据。

支持项目现有 `zh-Hans`、`zh-Hant`、`yue-Hant-HK`、`en`；字段代码稳定，标签本地化。文本放大时摘要与筛选可换行，图表提供语义说明及等价月度表。动画尊重系统减弱动态效果。表格不依赖悬浮交互，手机可通过展开／横向滚动读取完整字段。

### 4.3 开发及上线前必须完成的核验

1. 读取字典及真实 CSV，确认编码、BOM、多行表头、月份格式、备注区、重复行与排列方向。
2. 列出精确源字段 → 规范字段映射；明确类别定义、地域粒度、面积基准、单位／基期、覆盖类型与排除范围。
3. 核实平均租金的统计基础，不把挂牌、实际租赁统计和推算混称；核实指数与平均租金为何具有不同可比性。
4. 确认官方整体系列是否存在，默认值及每个可用筛选组合确实对应源系列。
5. 检查近五年历史覆盖、至少一个缺值／修订案例或官方规则；确认频率和方法是否中途改变。
6. 核实暂定、修订、样本不足等原文标记；保留原标记，未经映射的标记不直接判定为最终值。
7. 核实统计期、源发布／更新时刻是否存在；没有的字段保持缺失，不用抓取时间代替。
8. 核对来源使用条款、来源署名、快照保存及再展示限制；本地和生产网络均确认能访问固定源。
9. 形成经过审核的可比系列清单、计算样本和 parser 映射版本。无法核实的指标不开放。

普通开发前置可用经许可取得的真实样本；不得用随机数据冒充官方接口。演示样本必须明确标为虚构，不作为可上线证据。

## 5. 指标、时间与比较规则

以下为规范化后的内部计算规则，不声称与尚未读取的源字段同名。

### 5.1 指标定义

- `rental_index`：官方租金指数原值，保留基期和统计方法；不是港币金额。
- `average_rent`：官方平均租金原值；只有单位、地域、类别及计算基础核实后才注册为可用指标。
- `series_id`：经审核的稳定内部标识，不用翻译后名称当主键。
- 不将指数乘用户租金输出“应该租多少”；不将面积类别平均租金乘面积输出单位估价。
- 不自行平均指数、平均租金或不同地域数据生成官方不存在的整体系列。

### 5.2 月度时间轴

设当前指标已发布有效快照的统计锚点为月份 `T`，用户选择 `Y ∈ {1, 3, 5}`：

- 请求区间为 `[T - 12Y个月, T]`，含两端；完整数据对应 13／37／61 个按月节点，分别表示 12／36／60 个月跨度。
- 近一年不是仅取最后 12 行，因为年度端点比较需要去年同月。区间标签显示精确起止月份，避免月份数量误解。
- `T` 必须来自经核实的统计月份，不是今天、请求时间、目录修改日或最近成功检查日。
- 单一指标多系列拟共享同一快照与统计锚点，不因某条系列缺少最新值而静默将该系列向前移一个月。
- 单系列最新月缺值时显示“该月暂无数据”；如显示上一有效值，必须标其真实月份，不冒充 `T` 的值。
- 只提供月度序列，不拼接年度均值或季度值填补月份。历史不足时展示实际覆盖范围和不足说明；不把第一条可用记录当成原定区间端点。

### 5.3 最新摘要与区间计算

服务端以未展示舍入的数值计算，客户端仅格式化。比较必须同系列、同口径、分母存在且合法：

| 指标 | 计算规则 | 无法计算时 |
| --- | --- | --- |
| 环比 | `(v[T] / v[T-1] - 1) × 100%` | 任一精确月份缺失、分母不合法或跨口径断点时返回空值及原因 |
| 同比 | `(v[T] / v[T-12] - 1) × 100%` | 不用最近一条记录代替去年同月 |
| 区间变化 | `(v[T] / v[T-12Y] - 1) × 100%` | 原定起止端点缺失时显示暂无，不静默缩短区间 |
| 相对变化 | `r[t] = v[t] / v[start] × 100` | 无合法共同起点时不生成归一化比较 |

百分比是相对变化，不是百分点差；指数点数差也不能当成百分比。月度涨幅不能直接求和当年度涨幅。零分母不计算；源中的 `0` 是否有效取决于核实后的定义，不能将所有零一概视作缺失，也不能将缺失转成零。

内部缺月不影响合法端点比值本身，但曲线断线并提示覆盖不完整，不能声称期间走势连续或逐月上涨。发生基期／方法改变时，只有官方提供衔接规则并经核验后才跨断点计算；归一化也不能消除口径不兼容。

显示精度、舍入方式需与源精度及 UI 评审一起确定。底层方向由真实值决定；显示精度下趋近零时可用“变动小于显示精度”避免将微小上涨写成持平。

### 5.4 多系列比较

- 最多三条，必须同指标、月度频率和审核后的 `comparison_group`；原值比较额外要求单位、基期一致。
- 地域／类别不同可以是比较对象，但其方法、样本语义及可比范围必须得到官方依据支持，而不是仅列名相似。
- 相对模式用所选区间精确起点作为共同基准；若任一系列该月缺值，提示该组合无法归一化，不给每条线各自找起点。
- 所选共同区间末月某系列缺值时保留缺值；不前移末月，不补值，不偷偷移除系列。
- 允许单系列有效、不兼容组合被拒绝；不为满足“至少三条线”拼凑不兼容系列。
- 不根据相对涨幅给租金高低排名，也不把平均租金低解释为更划算或更适合居住。

### 5.5 事实型一句话

由机器可读计算结果和本地化模板生成，不调用模型。可表达“较上月上涨”“低于去年同月”“过去所选区间累计下降”；连续涨跌仅在精确相邻月份均有效且口径连续时计算。

不能表达“人才流入推动租金上涨”“租金即将见顶”“现在适合租房”“房东加租合理”。当最新值或比较基准缺失时，不生成相应断言。没有观察到新月份，只能说“当前可展示数据截至某月”，不能未经证据写“官方尚未发布”或“官方延迟”。

### 6.3 采集与发布（拟议）

1. 每个已审核来源注册固定 HTTPS URL、parser 版本与字段映射。客户端不能传入来源 URL、下载路径或任意 SQL。
2. 独立 `rent-worker` 使用同一服务端镜像。**建议初始按日检查**月更资源，具体时刻、重试间隔和限流在许可及真实源行为核实后确认；没有每秒轮询或实时 SLA。
3. 单实例调度或数据库 advisory lock 防重复发布；网络抓取与解析先在事务外完成，短事务内锁定、去重与切换快照，避免长时间网络等待占数据库事务。
4. 设置超时、响应体大小上限、有限重试；限制跳转主机。具体阈值根据实际文件大小和部署网络确定，不预设未验证的容量。
5. 校验编码、结构、频率、月份、字段、数值及原标记；检测 HTML 错误页、截断、历史骤减、重复冲突和未知字段。允许源明确声明的合法缺值，不将“每个月都非空”当成强制条件。
6. 有效内容按源形成完整规范化快照。异常只更新尝试／失败状态，不切换当前有效快照，不将部分解析结果覆盖历史。
7. 同一内容重复检查幂等，不积累每天一份相同月度数据；只更新 `last_checked_at`。源修订历史值时形成新的有效快照，查询按新快照重算历史涨幅。
8. 元数据或口径变化也参与版本变化，不只比较数字。parser 升级需要重新校验，而不是将旧快照直接视作新契约。
9. 发布原子切换当前源快照。指数与平均租金独立发布／降级；一个来源故障不能隐藏另一已核实指标。

新月份“没有变化”不是失败。成功下载也不等于源完整有效，更不等于官方发布新统计；抓取成功、校验成功和数据发生变化分别记录。

### 6.4 最小存储草案

考虑数据是有限的月度表，拟采用**有效快照 JSONB + 来源状态**两类表，不预建逐日观测、队列、通用数据仓库。表名与字段是新设计，不是现有表结构。

| 表 | 建议字段 | 语义 |
| --- | --- | --- |
| `rent_snapshots` | `id`、`source_id`、`content_hash`、`parser_version`、`accepted_at`、`source_updated_at`（可空）、`coverage_start_month`、`coverage_end_month`、`catalog` JSONB、`series_data` JSONB | 规范化有效快照，包含已核实元数据、月度值、缺值原因与原标记；同源内容及 parser 版本幂等 |
| `rent_source_state` | `source_id`、`active_snapshot_id`、`last_attempt_at`、`last_checked_at`、`last_changed_at`、`last_attempt_status`、`last_error_code` | 当前有效快照指针、下载校验状态；失败不清空有效指针 |

建议索引／约束：`source_id` 唯一状态行；快照幂等键；活动指针只能引用同一来源的有效快照。校验完全部规范化数据后在事务内插入与切换；快照正文及来源定义不存用户数据或凭证。

规范化系列至少记录：稳定 ID、指标、地域代码、类别代码、单位、基期、频率、口径版本、可比组、经审核的官方定义与排除项。点记录至少含 `month`、`value`（可空）、`source_flag` 原值、`quality_status`、`missing_reason`、`comparability_break`。这些字段是内部模型；源字段映射仍待核验。

保留旧快照用于回退与修订追溯，但历史存储许可、保留数量和清理周期待确认，不能默认无限保存。原始二进制文件是否留存亦待许可与实际调试需要确认；最低要求保留来源 URL、版本/hash、映射版本与规范化结果。

### 6.5 时间、精度与缓存

- 统计月份使用 `YYYY-MM` 或月首日期，不作为 Unix 时间戳换算；抓取、检查和发布时刻保存 UTC，显示运维时间时转香港时区。
- 服务端用 Decimal 或等价确定性数值计算，拒绝非有限数；JSON 用规范数值，最终传输精度需通过源样本确认。Flutter 不以展示舍入数再算百分比。
- 不另加 Redis。API 先读取持久化快照；客户端同会话内缓存 provider 结果、切换筛选取消旧请求，并按环境／语言隔离。
- 首版建议不加高频自动刷新；进入、手动重试只读取服务端最近快照，不触发官方抓取。HTTP 缓存与 ETag 是否启用在接口评审确定；版本变化不能只由数字变化判断。
- 同步状态变化也会影响响应，不用未包含状态与语言的 ETag 错误返回 304。

## 7. 只读 API 契约草案

以下均为**拟议新接口**，目前 `hkhub_server` 不存在这些路由。具体字段命名及 source → series 映射需要两端与真实数据一起定稿。

### 7.1 路由

| 建议路由 | 用途 | 参数及约束 |
| --- | --- | --- |
| `GET /api/rent/catalog` | 可用指标、系列、可比组合与数据状态 | 只返回核验后的可用元数据；未核验平均租金不作为可选项 |
| `GET /api/rent/trends` | 摘要、时间轴、曲线、区间变化和表格共用数据 | `series_id` 重复参数，1～3 条；`years=1/3/5`；`view=original/relative`；默认原值；同指标及可比组 |

客户端调用使用 `rent/catalog`、`rent/trends` 相对路径，保留既有 `API_BASE_URL` 中的 `/api/`。接口不需要新登录、不接受可控上游 URL、不开放客户端写接口。

### 7.2 目录返回语义

- 契约版本 `schema_version` 与有效快照 `snapshot_id`；每个指标当前可用性及来源状态。
- 指标、系列、定义、标签、单位／基期、地域／类别代码、频率、口径版本和 `comparison_group`。
- `default_series_id` 必须指向实际审核的系列；默认全港整体只有源确实提供时成立。
- 元数据提供实际组合，客户端不能推断不存在的筛选项。
- 不可用平均租金不展示标签页；如需要说明后续覆盖，在来源说明中以文字表达，不设置空功能入口。

### 7.3 趋势返回语义

| 对象 | 建议内容 | 约束 |
| --- | --- | --- |
| `dataset` | 快照 ID、来源、覆盖月、检查／变化时间、最近尝试状态 | 同一响应内同指标系列使用同一有效源快照 |
| `range` | `years`、锚点月、请求起止、实际覆盖、完整性 | 不因缺月静默缩短请求区间 |
| `series` | 系列定义、原值点、质量标记及缺值原因 | 缺失月份显式输出空值或等价 gap 元数据，前端不跨缺月连线 |
| `latest` | 精确锚点月原值、环比、同比及各自空值原因 | 旧月份值不冒充最新锚点；摘要计算不随年份切换改变 |
| `period_change` | 精确请求起止、端点值、累计百分比及原因 | 端点缺失或跨不可比断点时不算 |
| `relative` | 共同基准月、变换后点、变换定义 | 单独字段，不能覆盖官方原值；无法统一基准时拒绝相对模式 |
| `insight` | 模板代码、可用事实参数 | 客户端本地化，不给无依据的自然语言原因或预测 |
| `notes` | 官方定义、原标记及统计边界 | 有明确来源，未知口径不伪装成已知说明 |

目录获取与趋势获取之间可能发生快照更新。趋势响应携带完整使用版本及系列定义；客户端若发现版本变化，更新目录和定义再展示，不拼接旧单位与新点值。不存在的系列明确拒绝，不自动换成另一条线。

### 7.4 HTTP 与业务错误（建议）

| 情况 | 建议响应 | UI |
| --- | --- | --- |
| 有有效快照，最近同步失败 | `200`，数据 + `sync_failed` 状态 | 保留图表与统计月份，明确检查失败 |
| 合法缺月或最新点缺值 | `200`，空值 + 原因 | 断线；对应数值／涨幅暂无 |
| 目录中的已核实指标尚无有效快照 | 目录给不可用状态；趋势查询 `503 data_unavailable` | 不制造空数字；指数无数据时不能打开正常主页面 |
| 不存在或未开放的系列 | `404 series_not_available` | 提示重选／刷新目录 |
| 非法年份、空列表、超过三条 | 复用 `422 validation_error` | 不提交非法参数或清晰反馈 |
| 跨指标／不可比组合 | `422 incompatible_series` | 解释不兼容，不混线 |
| 相对模式共同基准缺失 | `422 relative_baseline_unavailable` | 提示改用原值或修改组合，不能静默换基准 |
| 数据库／API 不可用 | `503` 或现有平台错误 | 首次加载错误；同会话旧数据可保留但标明已是旧响应 |

错误体复用 `app/core/errors.py` 的 `error.code`、`error.message`、`details`、`request_id`，不返回凭证、堆栈或完整上游错误页。新增机器码的本地化需与现有平台实现对齐。

## 9. 降级、风险与待确认项

### 9.1 状态语义

分开记录并展示：**统计覆盖期、可获得的源更新时刻、最近成功检查、最近数据变化、最近尝试结果**。它们不是同一时间。

成功获取相同内容只能写“最近检查成功，数据截至某月”。只有有独立证据时才写“官方尚未发布新月份”；本服务抓取失败时写“同步失败，展示最近有效数据”。长期不变化是否异常，需要结合真实发布节奏确定；未验证阈值不擅自贴“过期”标签。

源停止更新、URL 迁移、字段或方法改变时，不继续把旧数字包装成最新市场，不用替代源静默拼接。指标可独立停用；保留其他有效指标及明确提示。API 故障与上游同步故障不同，后者有快照时仍可正常提供只读数据。

### 9.2 风险与待确认清单

| 项目 | 当前状态 | 实施前处理 |
| --- | --- | --- |
| 原始字段／字典 | 未取得可读正文 | 核实编码、单位、基期、类别、备注与精确列映射 |
| 地域粒度 | 指数目录明确全港；平均租金具体地域未读 | 不先承诺地区下钻，更不承诺屋苑 |

## 10. 实施顺序与验收标准

### 10.1 有依赖的实施顺序

1. **证据核验**：读取原始字典和真实月度数据，产出字段映射、定义、许可结论、有效系列与可比组；关闭阻塞指数上线的项。
2. **契约评审**：确认默认系列、入口、图表原值／相对模式、显示精度、时间轴和 API／存储契约。平均租金不能核验时从可用目录剔除，不阻塞指数。
3. **服务端数据链路**：migration、parser、快照发布、状态记录、独立 worker 及只读 API；不使用随机占位数据伪装可用。
4. **客户端页面**：同一响应驱动摘要、图表、比较、表格和口径；复用主题、语言、环境、错误层。
5. **部署验证**：确认生产网络能获取源、迁移已执行、任务独立运行且没有用户访问也会检查；无效更新不会覆盖有效快照。
6. **开放入口**：仅在指数主闭环通过验收后添加客户端可执行入口；平均租金后续按自身门槛开放。
7. **回退**：数据问题暂停对应源发布、回到上一有效快照并显式标版本／覆盖期；严重口径问题关闭对应指标或入口，不让旧快照冒充当前发布，不删除未评估的数据。

本轮只生成文档，上述实现、测试、迁移及部署均未执行；后续开发需单独授权。

### 10.2 可判定的验收标准

| 类别 | 验收行为／结果 |
| --- | --- |
| 默认与范围 | 首次进入指数、近一年；三年与五年可切换；没有全部历史、非住宅或生活成本入口 |
| 数据真实性 | 每个可选系列能追溯精确资源和源字段；未核实地域／类别不出现；不存在自造整体或单位估值 |
| 时间轴 | 完整区间有 13／37／61 个节点，起止精确相差 12／36／60 个月；缺月占真实时间位置 |
| 摘要 | 切换年份不改变主系列最新月环比／同比；区间变化同时更新并标精确起止 |
| 精确基准 | 去年同月缺失时同比为空，不取最近记录；端点缺失时区间变化为空 |
| 计算 | 以未舍入值求比值；不累加月涨幅。虚构算例 100 → 110 → 121 的累计变化为 21%，不是 20% |
| 缺值与断点 | 缺月断线，不填零／插值；源口径不可衔接时不跨断点计算，归一化也不绕过限制 |
| 指标隔离 | 指数与平均租金独立视图、准确单位；全港指数不能被地区筛选伪装成地区指数 |
| 比较 | 最多三条，同指标同审核可比组；不兼容请求被拒绝；不输出排名或更划算建议 |
| 相对模式（如启用） | 所有系列同精确起点，起点＝100；保留原值并明确变换；基准缺失有明确错误 |
| 表格 | 与图表使用相同快照和点值；默认折叠，缺值、原标记及月份可读取 |
| 内容边界 | 所有摘要可由响应事实重建，无原因、预测、个人合理租金或“利好”标签 |
| 幂等与修订 | 重复源内容不生成重复数据快照；历史合法修订形成新版本并重算，不只追加新月 |
| 更新失败 | 网络失败、HTML 错误页、结构异常或历史异常减少不切换有效快照；界面保留旧数据并准确标状态 |
| 时间语义 | 覆盖月份、检查时间、变化时间分开；相同内容检查不变成“官方刚发布” |
| 局部上线 | 平均租金未核实时没有空标签页；已核实指数仍可工作；指数未核验不开放正常入口 |
| 工程集成 | 请求经现有 `ApiClient`；语言／环境切换不混用响应；首页目录与原生路由白名单一致 |
| 安全 | 无可控源 URL、任意 SQL 或敏感错误返回；固定来源、受控跳转、响应上限和只读接口有效 |
| UI 与无障碍 | 不靠红绿或颜色单独表达；图例可辨、表格等价可读，文字放大可用，减弱动态效果得到尊重 |
| 运营追溯 | 能查来源、parser 版本、活动快照、最近尝试与有效检查；任务停摆与源未变化不混淆 |

虚构算例只用于校验算法，不代表真实租金。验收需使用核实过的源样本与受控异常样本；本轮没有执行测试或验证以上结果。
