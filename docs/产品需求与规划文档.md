# 📄 产品需求与规划文档：港汇通 (HK Hub)

## 1. 项目背景与立项初衷
在当前内卷极具竞争力的软件开发环境下，传统 C 端通用工具（如纯天气、纯乘车码、泛泛的工具箱）已被巨头与现有玩家深度占领。

香港作为国际金融中心与大湾区核心节点，拥有独特的法律、税制、牌照体系及跨境人才流动需求。平台如 `Data.gov.hk` 提供了大量结构化、权威且免费的官方 API 数据，但本地市场缺乏一款将 **“跨境通勤/人才身份服务（C端）”** 与 **“高价值商业数据与合规查询（B端）”** 高效整合的现代化聚合工具。

`港汇通 (HK Hub)` 旨在利用高效的技术栈（结合现代化 UI、自动化 API 胶水层与 AI 辅助能力），打造成一款轻量、极速、中英双语的香港全能数据与效能工具。

## 3. 核心功能规划（Modules & Features）

系统核心模块分为 **C端切入流量池（人才与跨境）** 与 **B端变现与高阶工具（商业与数据）**。

### 模块一：港深跨境通勤与口岸决策 (Cross-Border Commute)
* **实时过关指数：** 结合海关与运输署数据，提供深圳湾、福田、罗湖等核心口岸的实时过关等候时间及拥堵预测。
* **跨境交通联动：** 九巴/龙运/港铁等实时到站数据与口岸流量结合，推送最佳跨港/返深路线推荐。
* **桌面 Widget 挂件：** 支持 iOS/Android 桌面小组件，一键查看当前口岸人流状态。

### 模块二：新港人身份与续签计算器 (PR & Visa Tracker)
* **永居/续签“算日子”：** 根据入境处政策，记录用户在港停留天数，离港天数预警，自动计算符合“连续通常居住”7年永居标准的进度条。
* **续签材料合规清单：** 针对高才、优才、专才等不同签证类型，提供定制化的续签打卡提醒与文档整理建议。

### 模块三：港校申请与择校预测 (Education Predictor)
* **历史录取数据库：** 汇总港前八（HKU, CUHK, HKUST等）历年录取背景数据。
* **智能匹配预测：** 结合申请者的 GPA、语言成绩、专业背景，给出梯度推荐（保底/冲刺/匹配）与合规审核建议。

### 模块四：商业数据、牌照查询与 CSV 导出 (B2B Data Hub)
* **新开业与持牌机构监控：** 实时同步 `Data.gov.hk` 上的食肆牌照、酒牌、金融持牌机构等名单。
* **商业拓客工具（付费功能）：** 支持根据地区、牌照类型自动化筛选新开业店铺/公司，导出结构化数据（CSV/Excel），方便 B 端供应商（如餐饮设备、POS系统、会计师事务所）抢先拓展客户。
* **强检楼宇与招标监控：** 监控屋宇署强制验楼令（MBIS）及政府宪报招标信息，一键推送给本地工程商或服务商。

## 4. 技术架构与数据源设计

1. **前端技术：** Flutter / React Native（跨平台，一套代码快速出 iOS/Android/小程序版本）。
2. **后端与 API 架构：** Node.js / Go + PostgreSQL（高并发数据清洗与缓存），部署于香港/新加坡节点。
3. **数据源层（Data Layer）：**
   * 香港开放数据平台 API (`Data.gov.hk`)
   * 香港海关 / 入境事务处实时开放接口
   * 结构化爬虫与向量化知识库（RAG 准备）
4. **国际化（i18n）：** 原生支持**繁体中文、简体中文、英文**三语动态切换。

## 5. 商业变现路径（Monetization Strategy）

| 模式 | 适用于功能 | 详细说明 |
| :--- | :--- | :--- |
| **Freemium (免费+增值)** | 跨境通勤、永居计算、港校基础查询 | 基础功能完全免费，吸纳 C 端流量（新港人、留学生、跨境族）。 |
| **B 端 SaaS 订阅制** | 商业牌照监控、公司数据导出、招标订阅 | 面向 B 端企业按月/按年收取高级数据导出与实时推送通知费用。 |
| **精准广告/服务撮合** | 搬家、验楼工程、香港保险/财税咨询 | 在合规前提下，为优质的香港本地中介/机构提供精准展示位。 |
